## Telangana Farm Marketplace MVP Plan
- [x] Set up a persistent database for accounts, farmer verification and profiles, geocoded farms, crop listings and same-day photo evidence, conversations, order requests, Razorpay payment records, delivery confirmations, manual payout status, disputes, mandi comparisons, advisory content, and admin audit data; use a warm field-to-market visual identity with deep leaf green, turmeric gold, earthy cream, Telugu-aware typography, documentary crop photography, and distance/freshness as the visual centerpiece.
- [x] Build the bilingual customer and farmer experience: secure email/password signup and login with role-aware onboarding; English/Telugu toggle; location permission and Telangana address fallback; nearest-first listings with progressive radius expansion; searchable crop cards and detail views showing farmer price versus local mandi average, harvest/listed timestamps, quantity, verified-partner badge, same-day photo proof, voice introduction, farmer listing creation/editing, and a sourced static ICAR/KVK crop advisory library.
- [ ] Build the buyer-seller transaction flow: listing-linked order requests, quantity and delivery details, threaded bilingual chat with voice-note playback, order status tracking, standard Razorpay/UPI checkout, clear platform-held status messaging, delivery confirmation, dispute entry, cancellation/error handling, and admin-controlled manual farmer payout recording without implying Razorpay escrow.
- [ ] Build the responsive admin panel and launch shell: manage and verify farmers/local-partner badges, review photo proof, oversee listings, orders, payment references, delivery confirmations, payout status, chats and disputes, maintain mandi reference prices and advisory entries, enforce role permissions and validation, provide useful loading/empty/error states, and configure the bilingual marketplace as an installable offline-tolerant PWA with manifest, icons, and service-worker behavior.
